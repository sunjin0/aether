## 一、产品需求文档（PRD）

### 1.1 用户角色

| 角色 | 说明 |
|------|------|
| 系统管理员 | 管理模型供应商、Agent 定义、工具注册、权限分配 |
| Agent 开发者 | 创建和配置 Agent、绑定工具、调试聊天 |
| 终端用户 | 通过界面与 Agent 对话、使用工具 |
| 审计员 | 查看运行记录、工具调用日志、会话审计数据 |

### 1.2 核心概念

| 概念 | 说明 |
|------|------|
| Model Provider | 大语言模型供应商（如 OpenAI、Azure），配置接入地址和密钥 |
| Agent | AI 代理的定义，包含系统提示词、模型参数、绑定的工具 |
| Tool | Agent 可调用的工具，可内建或通过 MCP 导入 |
| Tool Binding | Agent 与工具的关联关系，含优先级 |
| Conversation | 用户与 Agent 的完整会话 |
| Message | 会话中的单条消息（user/assistant/tool/interaction） |
| Run | Agent 单次运行的审计记录 |
| Knowledge Base | 知识库（V0.7+），用于 RAG |
| Workflow | 工作流（预留） |

### 1.3 功能需求

#### 4.1 模型供应商管理
- 增删改查供应商（名称、类型、API 地址、密钥、默认模型）
- 启用/禁用供应商
- 测试供应商连接

#### 4.2 Agent 管理
- 创建/编辑/删除 Agent（名称、编码、系统提示词、模型参数）
- 启用/禁用 Agent
- 复制 Agent

#### 4.3 工具管理
- 注册/编辑/删除工具
- 测试工具
- 安全策略控制

#### 4.4 工具绑定管理
- 绑定/解绑 Agent 与工具
- 调整工具优先级
- 启用/禁用绑定

#### 4.5 会话管理
- 创建会话、继续会话、关闭会话
- 查看会话历史消息

#### 4.6 聊天接口（非流式）
- 发送消息，接收完整响应

#### 4.7 SSE 流式接口
- 流式接收消息分片、工具调用、推理过程

#### 4.8 运行审计
- 查看运行记录列表和详情
- 运行统计

#### 4.9 工具调用日志
- 查看工具调用日志列表和详情

### 1.4 非功能需求

- **性能**：SSE 首 token 延迟 < 2s，工具调用 < 10s
- **安全**：API 密钥加密存储，权限控制基于 `@Permission`
- **可靠性**：异常场景降级处理，超时控制
- **可扩展性**：工具和模型供应商可插拔
- **国际化**：支持 i18n

### 1.5 明确不做

- 多模态（图片/视频理解）
- 模型微调
- 第三方 OAuth
- 实时协作
- 工作流执行（V0.7 预留）
- 知识库检索（V0.7 预留）
- 计费系统
- 插件市场
