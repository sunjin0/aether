# 企业身份接入说明

## 安全默认值

- OIDC、SCIM、SAML 默认关闭；生产环境不得通过共享用户令牌启用 SCIM。
- SCIM 必须配置独立 Bearer Token、固定 `tenant-id` 和隔离的 base path。
- SAML 启用前必须使用 HTTPS 元数据地址、HTTPS 回调地址和 IdP 证书；当前版本仅提供配置契约，未开放 SAML 登录回调。

## 上线顺序

1. 在密钥管理系统中配置 OIDC client secret、SCIM bearer token 和 SAML 证书，不写入仓库或日志。
2. 先在单一测试租户启用并验证身份元数据、SCIM Users/Groups 读取和租户边界。
3. 验证失败时关闭对应开关并轮换凭据；已生成的本地登录令牌不因 SCIM 配置变更而扩大权限。

## 回滚验收

- 关闭 OIDC/SCIM/SAML 后，新请求必须被拒绝或不再进入对应协议入口。
- SCIM 凭据只允许访问绑定租户，其他租户返回拒绝。
- 审计、Trace 和历史执行记录保留，不因身份配置回滚而删除。
