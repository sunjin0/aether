# Agent 平台产品需求文档（PRD）

> 版本：V0.1 文档基线
> 状态：已确认
> 范围：Agent 平台的产品需求、用户角色、核心概念、功能与非功能需求

---

## 1. 背景与目标

### 1.1 背景

当前系统已具备用户管理、权限控制、i18n、Redis、MyBatis-Plus 等基础能力。为扩展 AI 能力，需要构建一个可管理、可调用、可审计的 Agent 平台，支持多模型供应商接入、Agent 定义、工具调用和会话管理。

### 1.2 目标

- **短期（V0.1–V0.5）**：完成 Agent 平台的核心功能（模型管理、Agent 定义、聊天、SSE、工具调用）
- **中期（V0.6–V0.7）**：完善运营审计、权限、预留工作流和知识库结构
- **长期（V1.0）**：达到基础可用平台，支持对外提供 Agent 服务

---

## 2. 用户角色

| 角色 | 描述 | 典型操作 |
|------|------|----------|
| **系统管理员** | 平台运维人员 | 配置模型供应商、管理 Agent、查看审计日志 |
| **Agent 开发者** | 创建和配置 Agent 的人员 | 定义 Agent 提示词、绑定工具、测试对话 |
| **终端用户** | 使用 Agent 进行对话的人员 | 发起会话、发送消息、查看历史 |
| **审计员** | 查看运营数据的人员 | 查看运行记录、工具调用日志、会话统计 |

## 3. 核心概念

### 3.1 Model Provider（模型供应商）

- 定义：提供大语言模型 API 服务的供应商
- 属性：名称、类型（OpenAI/Azure/Anthropic/本地）、API 地址、API Key、默认模型、状态
- 示例：OpenAI（gpt-4）、Azure OpenAI、本地 Ollama

### 3.2 Agent（智能体）

- 定义：一个可对话的 AI 实体，包含提示词、模型配置、工具绑定
- 属性：名称、描述、系统提示词（system prompt）、关联模型供应商、关联模型、工具绑定列表、状态
- 生命周期：草稿 → 启用 → 禁用 → 删除（软删除）
- **预留字段（V0.2 表结构预留）**：
  - `max_tool_rounds`：INT，最大工具调用轮次，默认 1（V0.6 实现多轮）
  - `access_type`：VARCHAR(16)，访问类型 private/public，默认 private（V1.0 实现公开访问）

### 3.3 Tool（工具）

- 定义：Agent 可调用的外部能力，当前仅支持 HTTP 工具
- 属性：名称、描述、类型（HTTP）、URL、方法（GET/POST）、请求头模板、请求体模板、响应提取规则
- 安全：URL 白名单、请求头过滤、响应大小限制
- **预留字段（V0.2 表结构预留）**：
  - `cache_ttl_seconds`：INT，缓存 TTL（秒），默认 0 表示不缓存（V0.6 实现缓存）

### 3.4 Tool Binding（工具绑定）

- 定义：Agent 与工具的关联关系
- 属性：Agent ID、工具 ID、启用状态、调用优先级

### 3.5 Conversation（会话）

- 定义：用户与 Agent 的一次对话上下文
- 属性：会话 ID、用户 ID、Agent ID、会话标题、消息数、状态
- 生命周期：创建 → 进行中 → 关闭 → 归档

### 3.6 Message（消息）

- 定义：会话中的单条消息
- 属性：会话 ID、角色（user/assistant/tool）、内容、工具调用信息、token 数、时间戳
- 特殊消息：工具调用请求（`tool_calls`）、工具调用结果（`tool_result`）
- **预留字段（V0.2 表结构预留）**：
  - `edited`：TINYINT，0-未编辑，1-已编辑（V0.6 实现编辑）
  - `original_content`：LONGTEXT，编辑前的原始内容（V0.6 实现编辑）
  - `edited_at`：DATETIME，编辑时间（V0.6 实现编辑）

### 3.7 Run（运行记录）

- 定义：单次 Agent 调用的完整记录
- 属性：运行 ID、Agent ID、用户 ID、会话 ID、输入消息、输出消息、模型、token 消耗、耗时、状态、错误信息
- 用途：运营审计、成本分析、故障排查

### 3.8 Workflow（工作流）

- 定义：Agent 的多步骤执行流程（V0.7 预留）
- 属性：工作流 ID、名称、节点定义、边定义、状态
- 说明：V0.7 仅预留表结构，不实现完整功能

### 3.9 Knowledge Base（知识库）

- 定义：Agent 可检索的文档集合（V0.7 预留）
- 属性：知识库 ID、名称、文档列表、索引状态
- 说明：V0.7 仅预留表结构，不实现完整功能

## 4. 功能需求

### 4.1 模型供应商管理

- **新增供应商**：配置供应商名称、类型、API 地址、API Key、默认模型
- **编辑供应商**：修改配置信息（API Key 加密存储）
- **删除供应商**：软删除，关联 Agent 需处理（提示或级联禁用）
- **启用/禁用**：控制供应商可用状态
- **测试连接**：验证供应商 API 可连通
- **环境隔离**：复用现有 `application-dev.yml`/`application-prod.yml` 等 Spring Profile 机制，不同环境部署不同数据库实例，各自独立配置供应商信息

### 4.2 Agent 管理

- **创建 Agent**：填写名称、描述、系统提示词、选择模型供应商和模型
- **编辑 Agent**：修改提示词、模型、工具绑定
- **删除 Agent**：软删除，保留历史会话
- **启用/禁用**：控制 Agent 可对话状态
- **复制 Agent**：基于现有 Agent 创建副本（提示词、模型、工具绑定）
- **版本控制（预留）**：记录 Agent 配置变更历史
- **多轮工具调用（V0.6）**：支持 `max_tool_rounds` 配置，实现循环调用控制和防循环机制
- **公开访问（V1.0 预留）**：支持 `access_type` 配置，公开 Agent 通过 API Key 或签名验证访问

### 4.3 工具管理

- **注册工具**：填写名称、描述、类型、URL、方法、请求模板
- **编辑工具**：修改配置信息
- **删除工具**：软删除，解除关联绑定
- **测试工具**：手动触发工具调用，验证配置正确
- **安全策略**：配置 URL 白名单、请求头过滤规则
- **响应缓存（V0.6）**：支持 `cache_ttl_seconds` 配置，使用 Redis 按工具缓存调用结果

### 4.4 工具绑定管理

- **绑定工具**：将工具关联到 Agent
- **解绑工具**：解除 Agent 与工具的关联
- **调整优先级**：设置工具调用顺序（预留）
- **启用/禁用**：控制单个工具在 Agent 中的可用状态

### 4.5 会话管理

- **创建会话**：用户首次与 Agent 对话时自动创建
- **继续会话**：基于会话 ID 追加消息
- **关闭会话**：标记会话结束
- **删除会话**：软删除，用户可删除自己的会话
- **查看历史**：分页查询会话列表和消息详情
- **消息编辑（V0.6）**：支持编辑用户消息，编辑后后续 assistant 消息标记为失效需重新生成
- **消息删除（V0.6）**：支持软删除消息，删除后后续 assistant 消息标记为失效

### 4.6 聊天接口（非流式）

- **请求**：用户 ID、Agent ID、会话 ID（可选）、消息内容
- **处理**：
  1. 验证 Agent 和会话状态
  2. 组装上下文（系统提示词 + 历史消息）
  3. 调用模型 API
  4. 若模型返回 `tool_calls`，执行工具调用并返回结果给模型（V0.5 单轮，V0.6 多轮）
  5. 持久化消息和运行记录
  6. 返回模型回复
- **响应**：`WebResponse<MessageVO>`
- **权限**：仅登录用户可用（V0.5），公开访问 V1.0 后支持

### 4.7 SSE 流式接口

- **端点**：`GET /api/agent/chat/stream`
- **事件**：
  - `message`：模型生成的文本片段
  - `tool_call`：模型请求调用工具
  - `error`：模型调用或工具执行错误
  - `done`：流式响应结束
- **连接管理**：支持客户端断开、超时关闭
- **消息持久化**：流式结束后持久化完整消息，chunk 仅内存不持久化（V0.4）
- **chunk 日志（V0.6 可选）**：如需 chunk 级审计，可通过日志文件记录，保留 7 天

### 4.8 运行审计

- **运行记录**：每次 Agent 调用生成一条记录
- **查询**：按 Agent、用户、时间范围查询
- **统计**：调用次数、token 消耗、平均耗时、错误率
- **导出**：支持导出运行记录（预留）

### 4.9 工具调用日志

- **记录内容**：工具名称、请求参数、响应结果、执行耗时、状态
- **查询**：按 Agent、工具、时间范围查询
- **安全审计**：异常调用（黑名单 URL、超时、错误）高亮

## 5. 非功能需求

### 5.1 性能

- 聊天接口响应时间：非流式 P99 < 10s（含模型调用）
- SSE 首 token 延迟 < 500ms
- 并发支持：100 并发（V1.0 目标）

### 5.2 安全

- API Key 加密存储（AES）
- 工具调用 URL 白名单/黑名单
- 请求头过滤（禁止敏感头）
- 响应大小限制（防止内存溢出）
- 执行超时控制（防止挂起）
- 权限控制：基于 `@Permission` 体系
- **公开访问安全（V1.0）**：API Key 认证、签名验证、限流、配额控制

### 5.3 可靠性

- 模型调用失败：返回错误信息，记录运行记录
- 工具调用失败：返回错误给模型，记录工具调用日志
- 会话异常：不影响其他会话
- 数据一致性：消息和运行记录同时写入（事务）

### 5.4 可扩展性

- 模型供应商可插拔：新增供应商只需实现客户端接口
- 工具类型可扩展：当前 HTTP，后续可扩展 SQL、脚本等
- 工作流和知识库：V0.7 预留结构，后续平滑扩展
- **A/B 测试（V1.0）**：支持多版本 Agent 同时运行、流量分配、指标对比

### 5.5 国际化

- 错误消息支持 i18n（复用现有 `i18n.api` 体系）
- 管理界面文案支持多语言（预留）

---

## 6. 非目标（明确不做）

- **多模态**：当前仅支持文本对话，不支持图片、语音、视频
- **模型微调**：不提供模型训练或微调功能
- **第三方 OAuth 登录**：复用现有用户体系，不新增社交登录
- **实时协作**：不支持多用户同时编辑 Agent 配置
- **知识库检索**：V0.7 仅预留结构，不实现向量检索和 RAG
- **工作流执行**：V0.7 仅预留结构，不实现节点编排和状态机
- **计费系统**：不实现按 token 计费或充值功能（仅记录消耗）
- **插件市场**：不提供工具或 Agent 的分享/市场功能

## 7. 已确认问题

| 序号 | 问题 | 确认方案 | 优先级 | 实现版本 |
|------|------|----------|--------|----------|
| 1 | 是否支持多轮工具调用（工具调用后模型再次调用工具）？ | V0.5 支持单轮，V0.6 多轮（`max_tool_rounds` + 防循环机制） | 中 | V0.5/V0.6 |
| 2 | 模型供应商 API Key 是否支持按环境隔离（dev/prod）？ | 复用现有 `application-dev.yml` 等配置，不同环境部署不同数据库实例 | 低 | 部署规范 |
| 3 | 会话消息是否支持编辑和删除？ | V0.3 不支持，V0.6 预留（软删除 + 编辑标记 + 后续消息失效） | 低 | V0.6 |
| 4 | 是否支持 Agent 的 A/B 测试（多版本同时运行）？ | V1.0 后考虑，当前用 Agent 复制临时满足 | 低 | V1.0 |
| 5 | 工具调用的响应缓存策略？ | V0.5 不缓存，V0.6 预留（Redis 按工具配置 `cache_ttl_seconds`） | 低 | V0.6 |
| 6 | SSE 流式消息是否按 chunk 持久化？ | V0.4 按完整消息持久化，chunk 仅内存（可选日志审计） | 中 | V0.4 |
| 7 | 是否支持 Agent 的公开访问（无需登录）？ | V0.5 不支持，V1.0 后考虑（`access_type` + API Key + 限流） | 中 | V1.0 |
